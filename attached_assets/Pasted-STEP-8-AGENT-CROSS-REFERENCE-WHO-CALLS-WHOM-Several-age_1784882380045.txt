STEP 8 — AGENT CROSS-REFERENCE: "WHO CALLS WHOM"

Several agents use RAISE INTERNAL EVENT or FOR EACH with -customEvent to trigger other agents. Parse these from agent_actions.action_params:

If action_gid = 'RAISE INTERNAL EVENT', extract -internalEvent {EVENT_NAME} — this triggers other agents listening for that event.
If action_gid = 'FOR EACH', extract -customEvent DOMAIN.EVENT_NAME — this triggers a custom agent event.

Build a cross-reference lookup:

sql
-- Find all "raises" 
SELECT agent_gid, action_params FROM agent_actions 
WHERE action_gid IN ('RAISE INTERNAL EVENT', 'RAISE EVENT', 'FOR EACH') 
AND action_params LIKE '%Event%';

-- Match to listeners
SELECT agent_gid, event_gid FROM agent_events 
WHERE event_gid = '<extracted_event_name>';

Display this as a "Triggers" and "Triggered By" section in the Agent Workbench.
